# Отправка сообщения

### Настройка робота

Для отправки сообщения добавьте робота «\[OLChat: Telegram] Отправка сообщения». Для этого перейдите в **Роботы ‒ Создать ‒ Выбор стадии ‒ Другие роботы ‒ \[OLChat: Telegram] Отправка сообщения ‒ Добавить.**

<figure><img src="../../.gitbook/assets/Отправка сообщения (1).png" alt=""><figcaption></figcaption></figure>

Выполните настройку робот&#x430;**.** Для этого на добавленном роботе нажмите на кнопку «изменить», чтобы открыть интерфейс редактирования робота:

1. В поле **Линия коннектора** укажите линию, через которую планируете сделать отправку
2. Укажите **Тип идентификатора чата**. В качестве идентификатора может выступать **ID чата, Номер телефона** или **Имя пользователя**.
3. В зависимости от выбранного типа идентификатора, в поле **Идентификатор чата** укажите **Номер телефона, ID чата** или **username,** куда будет отправлено сообщение.
   *   <sup><kbd>Если в поле<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Идентификатор чата»**<kbd></sup> <sup><kbd> </sup><sup><kbd>вы выбираете вариант<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Номер телефона»**<kbd></sup><sup><kbd>, важно убедиться, что в настройках робота указано<kbd></sup> <sup><kbd> </sup><sup><kbd>**корректное поле с номером телефона**<kbd></sup><sup><kbd>.<kbd></sup>

       <sup><kbd>Например, если в карточке клиента заполнено поле<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Мобильный телефон»**<kbd></sup><sup><kbd>, а в настройке робота в строке<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Номер телефона»**<kbd></sup> <sup><kbd> </sup><sup><kbd>указана переменная<kbd></sup> <sup><kbd> </sup><sup><kbd>**\{{Рабочий телефон\}}**<kbd></sup><sup><kbd>, робот<kbd></sup> <sup><kbd> </sup><sup><kbd>**не сможет найти номер**<kbd></sup> <sup><kbd> </sup><sup><kbd>— в результате сообщение<kbd></sup> <sup><kbd> </sup><sup><kbd>**не будет отправлено**<kbd></sup><sup><kbd>.<kbd></sup>

       <sup><kbd>Чтобы робот корректно подставлял номер из<kbd></sup> <sup><kbd> </sup><sup><kbd>**любого**<kbd></sup> <sup><kbd> </sup><sup><kbd>заполненного телефонного поля, рекомендуем в строке<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Номер телефона»**<kbd></sup> <sup><kbd> </sup><sup><kbd>выбрать переменную<kbd></sup> <sup><kbd> </sup><sup><kbd>**\{{Телефон (текст)\}}**<kbd></sup><sup><kbd>.<kbd></sup>

       <sup><kbd>Указать её можно через меню<kbd></sup> <sup><kbd> </sup><sup><kbd>**«…» (три точки)**<kbd></sup> <sup><kbd> </sup><sup><kbd>напротив строки<kbd></sup> <sup><kbd> </sup><sup><kbd>**«Номер телефона»**<kbd></sup><sup><kbd>.<kbd></sup>
4. Введите текст **Сообщения.**
5. В поле **Публикация в чате открытой линии?** укажите каким образом отправленное роботом сообщение отобразится в чате Открытой линии. Доступны варианты: **Входящим сообщением в ОЛ, Без публикации в ОЛ** и **Исходящим в ОЛ.**

{% hint style="warning" %}
В настоящее время **Публикация в чате открытой линии** возможно только **Входящим сообщением!** Публикация **Исходящим в ОЛ** недоступна. Техотдел работает над добавлением такой возможности.
{% endhint %}

### Настройка активити (действия) бизнес-процесса

Для отправки сообщения из бизнес-процесса добавьте действие «\[OLChat: Telegram] Отправка сообщения».&#x20;

<figure><img src="../../.gitbook/assets/image (941).png" alt=""><figcaption></figcaption></figure>

Выполните настройку параметров действия:

1. В поле **Линия коннектора** укажите линию, через которую планируете сделать отправку
2. Укажите **Тип идентификатора чата**. В качестве идентификатора может выступать **ID чата, Номер телефона** или **Имя пользователя.**
3. В зависимости от выбранного типа идентификатора, в поле **Идентификатор чата** укажите **Номер телефона, ID чата** или **username,** куда будет отправлено сообщение.
4. Введите текст **Сообщения.**
5. В поле **Публикация в чате открытой линии?** укажите каким образом отправленное роботом сообщение отобразится в чате Открытой линии. Доступны варианты: **Входящим сообщением в ОЛ, Без публикации в ОЛ** и **Исходящим в ОЛ.**

{% hint style="warning" %}
В настоящее время **Публикация в чате открытой линии** возможно только **Входящим сообщением!** Публикация **Исходящим в ОЛ** недоступна. Техотдел работает над добавлением такой возможности.
{% endhint %}

<figure><img src="../../.gitbook/assets/image (942).png" alt=""><figcaption></figcaption></figure>

Остальные настройки можно оставить по умолчанию. Нажмите на кнопку «Сохранить».
