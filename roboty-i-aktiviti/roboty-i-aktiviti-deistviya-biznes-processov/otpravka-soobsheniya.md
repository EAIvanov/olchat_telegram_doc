# Отправка сообщения

### Настройка робота

Для отправки сообщения добавьте робота «\[Олчат: Telegram] Отправка сообщения». Для этого перейдите в **Роботы ‒ Создать ‒ Выбор стадии ‒ Другие роботы ‒ \[Олчат: Telegram] Отправка сообщения ‒ Добавить.**

<figure><img src="../../.gitbook/assets/Отправка сообщения (1).png" alt=""><figcaption></figcaption></figure>

Выполните настройку робот&#x430;**.** Для этого на добавленном роботе нажмите на кнопку «изменить», чтобы открыть интерфейс редактирования робота:

1. В поле **Линия коннектора** укажите линию, через которую планируете сделать отправку
2. Укажите **Тип идентификатора чата**. В качестве идентификатора может выступать **ID (идентификатор) чата, Номер телефона** или **Имя пользователя**.
3. В зависимости от выбранного типа идентификатора, в поле **Идентификатор чата** укажите **Номер телефона, ID чата** или **username (имя пользователя),** куда будет отправлено сообщение.

{% hint style="info" %}
Если в поле **«Идентификатор чата»** вы выбираете вариант **«Номер телефона»**, важно убедиться, что в настройках робота указано **корректное поле с номером телефона**.

Например, если в карточке клиента заполнено поле **«Мобильный телефон»**, а в настройке робота в строке **«Номер телефона»** указана переменная **\{{Рабочий телефон\}}**, робот **не сможет найти номер** — в результате сообщение **не будет отправлено**.\
Чтобы робот корректно подставлял номер из **любого** заполненного телефонного поля, рекомендуем в строке **«Номер телефона»** выбрать переменную **\{{Телефон (текст)\}}**.

Указать её можно через меню **«…» (три точки)** напротив строки **«Номер телефона»**.
{% endhint %}

4. Введите текст **Сообщения.**
5. В поле **Публикация в чате открытой линии?** укажите каким образом отправленное роботом сообщение отобразится в чате Открытой линии. Доступны варианты: **входящим сообщением в ОЛ, без публикации в ОЛ** и **исходящим в ОЛ.**

<figure><img src="../../.gitbook/assets/image (943).png" alt=""><figcaption></figcaption></figure>

Остальные настройки можно оставить по умолчанию. Нажмите на кнопку «СОХРАНИТЬ».

### Настройка активити (действия) бизнес-процесса

Для отправки сообщения из бизнес-процесса добавьте действие «\[Олчат: Telegram] Отправка сообщения».
