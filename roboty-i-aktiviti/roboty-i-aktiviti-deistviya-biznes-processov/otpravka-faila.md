# Отправка файла

### Настройка робота

Чтобы отправить файл, добавьте робота «\[Олчат: Telegram] Отправка файла». Для этого перейдите в **Роботы ‒ Создать ‒ Выбор стадии ‒ Другие роботы ‒ \[Олчат: Telegram] Отправить файл ‒ Добавить.**

<figure><img src="../../.gitbook/assets/image (398).png" alt=""><figcaption></figcaption></figure>

Выполните настройку робот&#x430;**.** На добавленном роботе нажмите на кнопку «изменить», чтобы открыть интерфейс редактирования робота:

1. В поле **Линия коннектора** укажите линию, которую планируете использовать.
2. Укажите **Тип идентификатора чата**. Это может быть **ID (идентификатор) чата, Номер телефона** или **Имя пользователя**.
3. В зависимости от выбранного типа идентификатора в поле **Идентификатор чата** укажите **Номер телефона, ID чата** или **username (имя пользователя),** куда будет отправлен файл.
4. В поле **Тип источника файла** выберите пункт **Прямая ссылка на файл, Битрикс24.Диск (ID файла), Файл из поля CRM (системы** управления взаимоотношениями с клиентами).
5. В зависимости от выбранного типа источника файла в поле **Прямая ссылка на файл, ID файла на диске, ID поля** укажите ссылку на файл, его ID или ID поля, в котором он находится.
6. В поле **Отправить как документ?** выберите **Да,** если хотите чтобы файл отправился как документ, без сжатия и потери качества, или **Нет,** если уменьшение размера файла допустимо.
7. В поле **Публиковать в чате открытой линии?** укажите, каким образом отправленное роботом сообщение отобразится в чате Открытой линии. Доступны варианты: **входящим сообщением в ОЛ, без публикации в ОЛ** и **исходящим в ОЛ.**
8. При необходимости в поле **Подпись** укажите текст, который будет прикреплён к отправляемому файлу. Поддерживается в документах, изображениях и видео.

<figure><img src="../../.gitbook/assets/image (360).png" alt=""><figcaption></figcaption></figure>

Остальные настройки можно оставить по умолчанию. Нажмите на кнопку «СОХРАНИТЬ».

5. В зависимости от выбранного типа источника файла в поле **Прямая ссылка на файл, ID файла на диске, ID поля** укажите ссылку на файл, его ID или ID поля, в котором он находится.
