# Олчат Telegram в карточке смарт-процесса

Чтобы отправлять сообщения через приложение **Олчат Telegram** непосредственно из карточки смарт-процесса, сначала необходимо включить его для этого смарт-процесса.

<figure><img src="../.gitbook/assets/image (509).png" alt=""><figcaption></figcaption></figure>

Раздел **Олчат Telegram** может быть скрыт, тогда его нужно добавить.

1. Откройте карточку элемента нужного смарт-процесса.
2. Перейдите в режим редактирования карточки.
3. Перенесите **Олчат Telegram** в меню, как указано на скриншоте выше.
4. Выйдите из режима редактирования карточки.

После этого в таймлайне появится вкладка **Олчат Telegram**.

Из неё можно выбрать аккаунт Telegram, указать получателя и отправить сообщение.

Получателя можно выбрать одним из способов:

* **Из карточки**.
* **По номеру**.
* **По имени пользователя (username)**.
