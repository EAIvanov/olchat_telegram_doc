# Отправка сообщений из карточки смарт-процесса

Если вы хотите отправлять сообщения в Telegram из карточки смарт-процесса, сначала необходимо включить приложение **Олчат Telegram** для этого смарт-процесса.

После включения в таймлайне карточки появится отдельная вкладка **Олчат Telegram**, из которой можно отправлять сообщения клиентам.

<figure><img src="../.gitbook/assets/image (509).png" alt=""><figcaption></figcaption></figure>

#### **Как добавить Олчат Telegram в таймлайн карточки Смарт-процесса**

1. Откройте карточку элемента нужного смарт-процесса.
2. Перейдите в режим редактирования карточки.
3. Включите встрокуй Олчат Telegram для смарт-процессов:

<figure><img src="../.gitbook/assets/image (1)ннн.png" alt=""><figcaption></figcaption></figure>

1. Выйдите из режима редактирования карточки.

После этого в таймлайне появится вкладка **Олчат Telegram**.

Из неё можно выбрать аккаунт Telegram, указать получателя и отправить сообщение.

Получателя можно выбрать одним из способов:

* **Из карточки**.
* **По номеру**.
* **По имени пользователя (username)**.
